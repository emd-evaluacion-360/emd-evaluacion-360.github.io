# EMD Evaluación 360

Entrada pública: https://emd-evaluacion-360.github.io/

Contenedor mínimo para la aplicación privada existente. Sin respuestas, preguntas, identidades o credenciales en este repositorio. El acceso requiere el enlace personal completo.

La entrada muestra una espera CSS ligera con consejos, aviso de demora a los 20 segundos y reintento. El arranque de Google dispone de hasta 90 segundos; mantiene el handshake de origen y nonce. `loading.js` y `loading.css` se comparten con el frontend privado y su fixture sintético.
